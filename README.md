# Session-1
In the first session I learnt about GIT and GITHUB.
Having no background knowledge about the two I was made to understand the difference between the two where GIT is a version control system and GITHUB is the online platform where I store, manage and share my projects.
I learnt about the different commands in GITHUB and their uses through the session and also the tutorial.
I also learnt that when I upload my project in GITHUB and make it to appear to the public, others can have access to it and even edit it and make corrections where possible.
